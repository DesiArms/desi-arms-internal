Moving a recipe between lenses

Settings do not transfer. A longer lens spreads the same 50 W over a wider spot, so power density drops — the same numbers that cut clean at 70 mm will look weak at 210 mm.

  • Treat each lens as a separate recipe. Same material on two lenses means two entries.
  • Going to a longer lens, the mark gets lighter. Slow the speed first, one step at a time, before touching power.
  • Going to a shorter lens, the mark gets hotter. Speed up first — on polymer, too much density melts instead of marks.
  • Hold frequency where the proven recipe had it. It's the last thing to change, not the first.
  • Re-focus and load the matching lens correction file after every swap. A recipe run on the wrong correction file isn't the recipe.

Holding the part

  • Line the part up off a flat, solid spot — the spine of a blade, the flat end of a magazine. Never a curved edge or a tip, because those are never the same twice.
  • Set your focus from the surface you're marking, not from the table underneath it.
  • The holder has to sit in the same place on the bed every time. Use locating pins or push it into a hard corner.
  • For magazines: flat end of the baseplate against the stop, one flat side against the edge. Same way every time.
  • When you change lenses, the part sits a different distance from the laser. Re-check your focus after every swap.
  • If the same job keeps coming back, 3D print a holder the part drops into. It'll save you the setup every time.

Working out new settings

While you're testing

  • Write down which lens you're on before anything else. Without that, the numbers are useless to whoever reads them next.
  • Change one thing at a time. If you change two and it looks better, you don't know which one did it.
  • Speed is usually what you adjust first. Leave frequency alone until speed and power are sorted out.
  • Settings that work on red plastic won't work on black. Every color gets its own entry.
  • Test on scrap that's in the same condition as the real thing. If the real one ships heat-treated and etched, test on one that is too.

Before you mark it "Proven"

  • Get the same result three times, on three separate pieces. Once isn't proof.
  • Write down the exact numbers, the lens, and how the artwork was set up. Someone should be able to repeat it without asking you.
  • Add it to the RECIPES list at the top of this page's code. That list is what this page is built from.
